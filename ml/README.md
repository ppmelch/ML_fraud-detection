# Machine Learning

Estructura base para el código de ML, inspirada en la separación por capas:
- `src/data`: preparación y particionado de datos.
- `src/modeling`: definición/entrenamiento de modelos.
- `src/evaluation`: evaluación de desempeño.
- `src/metrics`: métricas de fraude y negocio.
- `src/utils`: utilidades transversales de ML.

Por ahora solo se define la estructura; no hay implementación.
