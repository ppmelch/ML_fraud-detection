# Data

| File | Tracked | Description |
|---|---|---|
| `bank_transactions_data_2.csv` | yes | Source dataset — 2,512 unlabelled US bank transactions (Kaggle "Bank Transaction Dataset for Fraud Detection"). |
| `bank_transactions_data_2_full.csv` | yes | Working dataset — the source plus population-weighted synthetic rows so every US state has coverage. Generated by `python -m scripts.augment_dataset`; synthetic rows carry a `TXS` / `ACS` id prefix. This is what `config.DATASET_PATH` points at. |

Other `*.csv` / `*.ipynb` here are git-ignored.
