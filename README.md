# Transaction Fraud Detection

Scaffold inicial del repositorio para un sistema de **detección de fraude en transacciones**.

> Estado actual: **solo estructura base** (sin implementación funcional).

## Objetivo del scaffold

- Separar claramente responsabilidades de Machine Learning, datos y experimentación futura.
- Preparar una base para arquitectura de agentes.
- Preparar una estructura de documentación y gestión del backlog por issues.
- Dejar configuración inicial de GitHub para estandarizar nuevos work items.

```text
.
```
