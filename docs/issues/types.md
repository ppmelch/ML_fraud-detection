# Tipos de Issue

- **Issue**: ticket genérico para seguimiento de trabajo.
- **Backlog**: ítem pendiente aún no calendarizado.
- **Feature**: capacidad nueva de producto/plataforma.
- **Experiment**: prueba controlada de hipótesis de datos/modelo.
- **Bug**: comportamiento incorrecto.
- **TechDebt**: mejora técnica sin cambio funcional directo.
- **Research**: investigación previa a implementación.
- **Task**: trabajo operativo delimitado.
